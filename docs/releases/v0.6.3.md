# SolFlash Relay 0.6.3

Release date: 2026-08-09

## 中文

- 修复接管 Haha 原生对话后发送失败的问题。Electron 会把外部 `app.asar` 当成归档路径处理，旧版的普通文件预检查因此错误返回 `ENOENT`；新版交由 Haha sidecar 直接加载。

- 已使用原 Haha `sessionId` 完成真实发送验证，`deepseek-v4-flash` 返回 `RELAY_SEND_OK`。
- 删除接口通过持久化验证：删除后任务详情返回 HTTP 404。

## English

- Fixes adopted Haha conversation delivery. Electron treated the external `app.asar` as an archive path, causing the old filesystem preflight to report a false `ENOENT`; the Haha sidecar now loads it directly.
- Adds persistent task deletion. Failed, completed, cancelled, or waiting tasks can be removed through the left status control, deleting them from the UI, API, and `tasks.json`.
- A real same-session check completed through the original Haha `sessionId`, with `deepseek-v4-flash` returning `RELAY_SEND_OK`.
- The deletion endpoint was verified to return HTTP 404 after persistent removal.
