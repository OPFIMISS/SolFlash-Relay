# SolFlash Relay 0.6.2

发布日期 / Release date: 2026-08-09

## 中文

### 后台可见性

- 关闭主窗口后改为最小化，不再只调用 `hide()`；任务栏始终保留 SolFlash Relay 入口。
- MCP 自动拉起后台宿主时会创建最小化窗口，同时保留任务栏和系统托盘入口。
- 托盘对象异常丢失时会自动重建；托盘图标加载失败会明确报错，不再静默留下孤立进程。
- 第二次启动程序会恢复并聚焦现有最小化窗口。

### 退出与升级修复

- 修复退出死锁：旧逻辑等待 HTTP 服务关闭时，隐藏窗口仍保持事件流连接，导致进程无法结束。
- 新逻辑先销毁窗口和事件连接，再关闭 Relay Runtime、托盘和 Electron 主进程。
- 增加打包版专用的 `--quit-for-update`，确定性终止同名 Relay 进程树，不依赖偶发丢失的单实例消息。
- Setup 安装与卸载前会清理残留的 Relay 主进程、GPU/网络子进程和 MCP 进程，避免反复提示“SolFlash Relay 未关闭”。

### 验证

- Electron 桌面测试确认正常启动窗口可见。
- 关闭后确认窗口仍存在且已最小化，`taskbarReady=true`、`trayReady=true`。
- 打包后 EXE 实测 `--quit-for-update` 能终止完整后台实例。
- Setup/Portable 构建、打包后 MCP、桌面通知、任务栏未读角标和 UI 响应式测试通过。

## English

### Visible background hosting

- Closing the main window now minimizes it instead of only calling `hide()`, preserving a SolFlash Relay taskbar entry.
- MCP-triggered background startup creates a minimized window while keeping both taskbar and system-tray entry points.
- A missing tray object is recreated automatically, and tray icon load failures now fail explicitly instead of leaving an unreachable process.
- Launching Relay again restores and focuses the existing minimized window.

### Exit and upgrade fix

- Fixes an exit deadlock where the hidden renderer's event stream kept the HTTP server open while shutdown waited for that server to close.
- Shutdown now destroys the window and its connections before closing the Relay runtime, tray, and Electron process.
- Adds a packaged-only `--quit-for-update` command that deterministically stops the Relay process tree without relying on single-instance message delivery.
- Setup and uninstall clean up residual Relay, GPU/network child, and MCP processes before replacing files.

### Verification

- Electron desktop testing confirms that normal startup remains visible.
- After closing, the window remains minimized with `taskbarReady=true` and `trayReady=true`.
- The packaged EXE was verified to terminate the complete background instance through `--quit-for-update`.
- Setup/Portable builds, packaged MCP, notifications, unread taskbar badge, and responsive UI tests passed.
