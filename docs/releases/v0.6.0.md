# SolFlash Relay 0.6.0

发布日期 / Release date: 2026-08-09

## 中文

### 接管已有 Haha 对话

- 按项目绝对路径扫描 Claude Code Haha 原生会话。
- 显示原会话标题、实际模型、更新时间和最近回复。
- 自动建议当前 Git 改动文件作为允许范围。
- 复用原 `sessionId` 发送 Sol 的第一条纠偏指令，不创建新对话。
- 自动排除 `Unknown skill: usage` 探测会话。

使用前请先等待或停止 Haha 当前生成，避免两个进程同时写入同一会话。

### Token Monitor 兼容性修复

- 检测 Token Monitor 0.42.1 的 Claude `/usage` 轮询风险。
- 在 Relay 的连接区域显示明确警告和一键修复按钮。
- 修改前自动备份 `settings.json`。
- 仅从 `limitProviders` 移除 `claude`，保留其他 Provider、凭据、用量历史和已有 Haha 对话。
- 修复后需要退出并重启 Token Monitor。

## English

### Adopt existing Haha conversations

- Scan native Claude Code Haha sessions by exact project path.
- Show the original title, effective model, update time, and latest reply.
- Suggest the current Git-changed files as the allowed scope.
- Resume the original `sessionId` with Sol's first correction instead of creating a new conversation.
- Filter out `Unknown skill: usage` probe sessions.

Wait for or stop the active Haha generation before adoption so two processes do not write to the same session concurrently.

### Token Monitor compatibility repair

- Detect the Claude `/usage` polling risk in Token Monitor 0.42.1.
- Show a clear warning and one-click repair action in Relay.
- Back up `settings.json` before modification.
- Remove only `claude` from `limitProviders`, preserving all other providers, credentials, usage history, and Haha conversations.
- Restart Token Monitor after applying the repair.
