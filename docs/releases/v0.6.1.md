# SolFlash Relay 0.6.1

发布日期 / Release date: 2026-08-09

## 中文

### Haha 会话扫描修复

- 修复同一项目有三个 Haha 对话时只显示两个的问题。
- 使用 `session-meta.workDir` 与 `repository.requestedWorkDir` 判断会话原始项目，不再被后期消息进入子目录影响。
- 流式读取完整 JSONL，会话再大也能找到位于文件中段的标题记录，同时避免一次性载入整个文件。
- 读取 Haha 原生 `ai-title.aiTitle`；没有 AI 标题时使用第一条真实用户提示。
- 忽略内部 `<task-notification>`，不再把任务通知 XML 当成标题或最近提示。

### 对话区分

- 接管后的任务标题与 Haha 侧栏标题一致。
- B 执行对话栏显示原 Haha 标题和短 `sessionId`，同一项目的多个会话更容易辨认。
- 接管弹窗底部同时显示所选会话标题和短 `sessionId`。

### 实机验证

- 在真实项目路径中识别到全部 3 个 Haha 会话，标题与 Haha 侧栏一致，实际模型均为 `deepseek-v4-flash`。
- 通过 TypeScript、构建、Haha 会话回归、MCP、服务端、Agent 路由、Playwright 桌面/移动 UI 和 Electron 桌面烟雾测试。

## English

### Haha session discovery fix

- Fixes projects where Haha displayed three conversations but Relay found only two.
- Uses `session-meta.workDir` and `repository.requestedWorkDir` as the canonical project identity, instead of a later message's subdirectory.
- Streams the complete JSONL so title records in the middle of large sessions are found without loading the whole file into memory.
- Reads Haha's native `ai-title.aiTitle`, falling back to the first real user prompt when no AI title exists.
- Excludes internal `<task-notification>` messages from titles and latest-prompt previews.

### Conversation identification

- Adopted task titles now exactly match the Haha sidebar title.
- Executor conversation B shows the original Haha title plus a short `sessionId`.
- The adoption dialog footer shows both the selected title and short `sessionId`.

### Real-data verification

- Confirmed all three native Haha conversations under the reported project path, with matching titles and `deepseek-v4-flash` as the effective model.
- Passed TypeScript, production build, Haha-session regression, MCP, server, Agent routing, Playwright desktop/mobile UI, and Electron desktop smoke tests.
